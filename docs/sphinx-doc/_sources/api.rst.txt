DIAGNOSTICS
~~~~~~~~~~~

.. data:: domain.image.DIAGNOSTICS

   Diccionario que mapea los IDs de clase a información de diagnóstico.

   .. code-block:: python

      DIAGNOSTICS = {
          0: {"abbr": "Normal", "name": "Normal"},
          1: {"abbr": "dAMD", "name": "Degeneración macular asociada a la edad (seca)"},
          # ... más diagnósticos
      }
